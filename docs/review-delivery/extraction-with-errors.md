# 草稿提取方案：含异常处理

日期：2026-10-19。

**状态：提取主线基于0.10.1；异常恢复包含tec01侧需配套实现的职责，不代表本仓库已实现tec01功能。**

tec01主动提交工单数据并保存进度和草稿；提取服务过滤操作、调用内网LLM并生成结构化流程，人工修正审核后再发布。

## 1. 草稿提取与审核发布

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户 / 审核人
    participant T as tec01（页面与存储）
    participant E as itsm-workflow（提取服务）
    participant L as 内网LLM

    U->>T: 申请从工单提取经验
    T->>T: 获取工单详情与操作记录<br/>保存提取任务
    T->>E: 主动提交工单数据
    E->>E: 校验请求与重复提交
    E-->>T: 已受理，后台开始处理
    E->>E: 过滤失败与非只读操作<br/>去重并参数化SQL
    E-->>T: 回报阶段进度与过滤情况
    T->>T: 保存进度
    T-->>U: 展示当前提取阶段
    E->>L: 提交任务背景与候选步骤
    Note over T,L: 进入分析时回报一次，不发送定时心跳；提取不执行历史SQL
    L-->>E: 返回中文语义与结构化分析
    E->>E: 组装流程草稿并校验
    E->>T: 返回草稿、校验结果与过滤说明
    T->>T: 保存草稿
    T-->>E: 确认保存成功
    E->>E: 结束提取任务
    T-->>U: 展示可视化草稿
    U->>T: 编辑并提交审核
    T->>E: 提交发布前流程校验
    E-->>T: 返回校验结论与规范化定义
    alt 校验通过且人工审核通过
        T->>T: 保存不可变发布版本
        T-->>U: 发布完成，可以后续使用
    else 校验或审核未通过
        T-->>U: 展示问题，返回编辑或退回草稿
    end
```

## 2. 输入、模型、校验、回报与中断异常

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户 / 审核人
    participant T as tec01（页面与存储）
    participant E as itsm-workflow（提取服务）
    participant L as 内网LLM

    alt 工单数据或请求不合法
        T->>E: 提交工单数据
        E-->>T: 拒绝受理，说明错误
        T-->>U: 修正工单数据后重新提交
    else 过滤后没有有效SQL读操作
        E->>E: 检查操作类型、成功结果与SQL
        E->>T: 返回无有效操作及过滤原因
        T->>T: 保存失败说明
        T-->>U: 核对来源操作，不生成可发布草稿
    else LLM超时、不可用或返回结构不合法
        E->>L: 请求结构化分析
        L--xE: 超时 / 请求失败 / 无效结果
        E->>T: 返回分析失败及可读原因
        T-->>U: 修正配置或稍后重新分析
        Note over T,E: 不用工单标题等简单替代内容自动生成可发布草稿
    else 草稿流程校验失败
        E->>E: 检查只读SQL、节点、依赖与连线
        E->>T: 返回校验失败原因
        T-->>U: 保留来源信息，修正后重新提取或编辑
    else 进度或终态回报失败，或保存确认丢失
        E->>T: 重试回报同一次进度或结果
        T->>T: 重复回报只处理一次<br/>旧回报不覆盖较新的提取
        alt 最终保存并确认
            T-->>E: 确认原结果已保存
        else 重试上限到达
            E->>E: 停止重发并告警<br/>仅短期保留可核对结果
            T-->>U: 提示结果同步异常，先核实再重提
        end
    else 提取服务重启，或进度长期没有更新
        T->>T: 检查最后保存的进度与结果
        T-->>U: 提示提取中断或结果待核实
        alt 已保存草稿
            T-->>U: 展示已保存草稿，不重复创建
        else 无结果且确认旧任务不再执行
            T->>E: 基于原工单数据发起新一轮提取
        end
        Note over T,E: 新旧提取轮次必须区分；提取重做不执行生产SQL，但仍需防止旧草稿覆盖新草稿
    end
```

## 异常处理说明

| 情况 | 处理方式 |
|---|---|
| 工单数据不合法 | 拒绝受理，提示修正；工单详情传data对象，操作记录传data数组 |
| 工单ID不一致或重复请求冲突 | 拒绝错误请求，不重复分析 |
| 过滤后无有效SQL | 返回过滤原因，不生成可发布草稿 |
| LLM超时、不可用或返回结构不合法 | 返回明确分析失败，修正配置或稍后重新分析 |
| 草稿组装或流程校验失败 | 返回可读原因，保留来源信息供修正，不自动发布 |
| 进度或结果回报失败 | 重试回报同一次内容，不重复创建草稿 |
| tec01已保存但确认丢失 | 重复回报只处理一次，并再次确认已保存结果 |
| 回报重试上限到达 | 告警并提示同步异常，不直接把同步失败当作分析失败 |
| 提取服务重启或长时间未收到终态 | 核对最后保存的进度、结果及旧任务状态，提示中断或结果待核实；不能按15秒无心跳判失败 |
| 已保存草稿但页面未更新 | 展示tec01已保存的草稿，不重复创建 |
| 无草稿且确认旧任务不再执行 | 基于原工单数据发起新一轮提取，区分新旧轮次 |
| 旧提取轮次回报晚到 | 不得覆盖新一轮的进度、草稿或审核状态 |
| 人工审核或发布前校验未通过 | 返回编辑或退回草稿，不能直接发布 |

## 提取边界

- 仅从明确成功的安全单条SQL读操作形成候选；失败、无效、非读和重复操作记录过滤原因。
- LLM只参与草稿语义提炼，不是运行时节点，不执行历史SQL。
- 无有效操作、模型失败或校验失败时，不以工单标题等简单替代内容生成可发布草稿。
- 自动草稿以SQL读流程为主，条件、人工表单及结果绑定仍需人工核对或补充。
- 提取重做不执行生产SQL，但仍需区分任务轮次，防止旧回报覆盖新草稿。
- 提取服务的内存缓存不是持久化保障；生产进度、草稿、审核和版本由tec01保存。
- Studio可用浏览器存储独立调试，但不能替代生产持久化。
